## 发布前补强

- Docker 导入脚本通过子进程环境传递连接串，避免密码进入命令行和
  `CalledProcessError` 的命令文本；补故障路径测试。
- 空表判断改为 `EXISTS`，避免每次启动全表计数；对真实本机数据库的三个
  存在性查询均成功。脚本/迁移 COPY 层移到固定编码器下载之后，减少缓存失效。
- 标注审计的 CSV/Markdown 校验统一使用 LF 文本哈希，兼容 Git 的 CRLF/LF
  checkout 转换；Parquet 仍按原始字节校验，裁定内容和输出摘要不变。
- 复用已有流式文件哈希；LTR 诊断中每批只构建一次类别映射；权重对照使用
  `dataclasses.replace`，保持所有其他模型字段不变。

四个 simplify 视角分别复核复用、简化、效率和实现层次；接受以上行为保持的
清理，不合并语义不同的分位数、标注读取和独立 Agent 判分逻辑。
