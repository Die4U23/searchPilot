# 2026-10-22 向量启动预热与 HTTP 验证

此前默认应用可以在模型尚未加载时返回 ready，把初始化成本留给首个向量请求。
本轮新增 `SEARCHPILOT_VECTOR_WARMUP`：启动工厂在挂载向量能力前执行一次固定查询
`search warmup`，校验输出维度、有限值及非零。复用同一编码器，不更换模型、查询前缀、
评分或标签。Python 默认关闭以保留原行为，Docker/Compose 默认开启，可显式设为 false。

实际编码失败时只记录异常类名，保留 BM25；`vector_index=false` 使 ready 返回 503，
向量、混合、LTR 请求返回 503。修复后需要重启，没有后台重试。向量索引损坏继续沿用
原有加载失败行为。预热是同步启动步骤，不提供超时取消；部署应使用已有离线模型缓存。
容器健康检查仍是 liveness，流量准入需使用 readiness。

## 本轮真实对照

基于 `2a47ed18abd14a341cb7be20cf19b04c64d90d11` 加本轮改动，四次独立进程按
A–B–B–A 顺序运行同一份代码，唯一配置差异为预热开关。Windows 11、Python 3.12.6，
实际 `build_default_app()` 与单 worker Uvicorn，完整本地数据版本 `d3a904f41240`。
无数据库配置、内存反馈；设置模型离线标志，不读取 `.env`，外部 LLM 调用 **0 次**。
进程是冷启动，文件系统与模型文件缓存未清除，不是冷磁盘或首次下载测试。

| 轮次 | 预热 | 启动到 HTTP ready（秒） | 首次向量请求（秒） | 前两项之和（秒） |
|---|---|---:|---:|---:|
| A1 | 关闭 | 22.820 | 9.382 | 32.202 |
| B1 | 开启 | 32.530 | 0.086 | 32.616 |
| B2 | 开启 | 36.359 | 0.050 | 36.409 |
| A2 | 关闭 | 25.228 | 8.253 | 33.480 |

两轮均值：首次向量响应 **8.817 → 0.068 秒**，启动到 ready **24.024 → 34.444 秒**。
这是将初始化工作前移，**没有证明总冷启动加速**。表中和不含 ready 与业务请求之间
额外的 live 探测，不能直接作为启动到首个业务完成的端到端计时。

每轮依次执行 `microsoft/vector`、`weather/vector`、`microsoft/bm25`、
`microsoft/hybrid`、`microsoft/ltr`，预热文本与业务查询不同。共 **20/20** 请求返回
200 和 5 条结果；去除随机 `request_id` 后，四轮所有响应字段（含分数、排序和模型版本）
精确一致。两轮开启预热的第二个不同向量查询分别为 84、46 毫秒。
每轮 ready 的 search/recommend/feedback/vector_index/ltr/ctr 均 true，live 为 200。
本轮只调用搜索业务接口，没有据此推断推荐或 CTR 打分已重新验收。

启动等待采用 `asyncio.timeout(120)`；每次搜索整个请求与响应解析采用
`asyncio.timeout(60)`，HTTPX 各阶段也设置 60 秒。请求前保存 pending，完成或失败后更新；
无自动重试。HTTP 请求采用 `perf_counter` 计时；工厂内部延用 `monotonic`。
四进程均优雅关闭、退出 0、端口释放。两轮/配置不能用于 p95/p99、统计显著性或 SLA。

独立编码器诊断首次为 15.613 秒、第二次为 0.017 秒，只定位初始化成本，不混入上表。
没有重跑 Docker 镜像、数据库整站、多 worker、并发或持续负载。另有历史就绪性边界：
CTR 加载失败成 None 时，现有 health 路由省略 CTR 检查；本轮未修改该语义。

## 回归与证据

新测试覆盖 lazy 默认、同一编码器复用、无向量产物、索引损坏、环境变量与工厂传参，
以及导入/编码异常、错误维度/形状、NaN、Inf、零向量；实际 HTTP 验证失败时
BM25=200、三种向量相关模式=503、live=200、ready=503，异常正文不得进入日志。

初次全量回归为 506 passed、2 failed、11 errors：新 LTR 测试夹具用了任意版本号，
改为既有 `assemble_ltr_model` 生成合法版本；另两项是已有 CTR 测试按 Windows 默认
GBK 读取 UTF-8 源码，已显式指定 UTF-8。没有修改 CTR 模型或特征行为。
定向回归随后 56 passed；最终本地全量 **519 passed、10 integration deselected**，
68 subtests passed。Ruff、格式检查、Mypy（73 文件）通过；Compose 默认预热配置解析通过。
PostgreSQL 集成结果以本次 PR 的 CI 为准；现存 TestClient 弃用警告不影响通过。
独立复审覆盖复用、简化与效率，主线程检查实现层次；采纳复用 `make_client` 夹具建议。
