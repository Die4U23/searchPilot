## 解读

- **向量在补标后仍是四路最强**（nDCG 0.8205，且比补标前更高）——此前 #31/#32 已说明向量前排大量文档缺分；补标后这些文档拿到了真实分数，向量优势坐实。
- **BM25 从 0.6396 降到 0.5642**：BM25 前 10 里有一批此前未标注、Claude 判为 0 的文档。补标把「BM25 前排基本都对」的假象拆穿了——原标注池主要来自 BM25 前 10，天然对 BM25 有利。
- **LTR 小幅回升**（0.4596 → 0.5072），但仍低于 hybrid 与 vector，负结果结论不变。
- **hybrid 略降**（0.7214 → 0.6834）：RRF 把 BM25 前排混进来后，在更完整标注下受 BM25 弱项拖累。

## 结论

补标后的排序结论：**vector > hybrid > bm25 > ltr**（按 nDCG@10）。与补标前的排序（vector > hybrid > bm25 > ltr）一致，但差距更真实：BM25 此前被偏置的标注池高估了约 0.075。
