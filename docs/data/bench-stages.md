# 分阶段计时

单进程顺序调用，没有 `--reload`。冷启动是该阶段的第一次调用，不计入后面的分位数。

- 机器：`Windows-11-10.0.26200-SP0`
- Python：`3.12.6`

- 向量 冷启动：15257.092 ms（1 次）

- RRF 冷启动：88.949 ms（1 次）
- RRF 预热后 30 次：p50 91.063 ms，p95 97.785 ms，p99 101.248 ms
- LTR 冷启动：132.388 ms（1 次）
- LTR 预热后 30 次：p50 127.444 ms，p95 135.619 ms，p99 135.783 ms
- CTR 冷启动：3.384 ms（1 次）
