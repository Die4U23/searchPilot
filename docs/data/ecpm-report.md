## 为什么校准可以不改变 pCTR 排序，却改变 eCPM 排序

温度缩放等校准是对 pCTR 的非线性单调变换，单独按 pCTR 排序时 Top-1 不变。eCPM = 合成出价 × pCTR；出价因物品而异，单调变换之后 Top-1 可以改变。本实验不做竞价、预算 pacing 或 CVR，结论不得表述为真实广告收益。
