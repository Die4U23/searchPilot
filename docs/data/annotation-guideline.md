# SearchPilot 查询相关性标注指南

## 相关性等级

- **3（高度相关）**：新闻直接、完整地满足查询意图；实体、主题及限制条件均匹配。
- **2（相关）**：主要意图匹配，但缺少次要条件，或新闻只覆盖查询主题的重要部分。
- **1（弱相关）**：仅有背景、上位概念或轻微关联，不能直接回答查询意图。
- **0（不相关）**：没有实质关联；仅命中歧义词、热门词，或查询明确无答案。

判断时以标题和摘要共同提供的信息为准，不根据新闻热度、点击量或排序位置改变等级。

## 六类查询的构造

目标总量约 100 条，同一语义不要通过微小改写重复计数。

1. **exact_entity（建议 20 条）**：从语料中选有辨识度的人名、机构、事件名或编号，例如
   `N12345 election update`。保留一部分只含精确实体的短查询。
2. **synonym（建议 16 条）**：用正文未必原样出现、但语义等价的表达改写，例如用
   `automobile market` 查询使用 `car industry` 的新闻。
3. **multi_condition（建议 18 条）**：组合至少两个可核验条件，如地点 + 主题、人物 + 时间，
   例如 `Seattle weather weekend`；缺少一个关键条件通常至多评 2。
4. **misspelling_or_abbrev（建议 16 条）**：加入真实可辨认的拼写错误或常用简称，例如
   `artifical inteligence news`、`Federal Reserve rate` → `Fed rate`，不要制造无法判断的乱码。
5. **no_answer（建议 15 条）**：构造语料中确认不存在答案的意图，例如
   `underwater city council on Mars`；候选通常标 0，用于测量系统是否把故障伪装成结果。
6. **long_tail_popular_distractor（建议 15 条）**：选择低频实体，并加入会召回热门但不相关
   新闻的常见词，例如 `small-town Orion school bond`，检查热门内容是否压过真正相关项。

以上建议合计 100 条。正式查询须人工核对语料；示例 CSV 仅用于说明格式，不计入正式结果。

## 双标与一致率

固定随机种子按 `query_id` 抽取不少于 20% 的查询，抽中的查询及其全部候选由第二名标注员
独立标注。标注员在对账前不得查看对方结果。

同时报告：

- **完全一致率** = 等级完全相同的双标样本数 / 双标样本总数；
- **相邻一致率** = 等级差绝对值不超过 1 的样本数 / 双标样本总数；
- **加权 Cohen's kappa**：采用二次权重，体现相差 1 级和相差 3 级的严重程度不同。

报告必须给出双标查询数、候选对数和三个指标。争议样本经讨论形成最终标签，同时保留两份
原始标注；不得只报告仲裁后的“一致率”。

## 查询级切分

先冻结并去重查询，再以固定随机种子按约 70% / 15% / 15% 分为 train / val / test。
切分单位是 `query_id`：同一查询的所有候选标签必须处于同一 split，近义改写组也应整体
分配，避免意图泄漏。test 在模型、规则与超参数确定前不得查看；索引语料保持固定，不随
查询 split 改变。每次发布查询集时记录随机种子和各类查询在三个 split 中的数量。
